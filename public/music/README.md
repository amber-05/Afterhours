# Background music

Drop royalty-free tracks here and Afterhours plays them instead of the built-in synth.

| File | Plays when the room's vibe is |
| --- | --- |
| `friendly.mp3` | Friendly (also used for Mixed and outside rooms) |
| `fun.mp3` | Fun |
| `romantic.mp3` | Romantic |
| `spicy.mp3` | Spicy |

Any missing file just falls back to the built-in synth. The track loops and cross-fades when the vibe
changes, and gets quieter for Confessions / Friendship Test.

## Where to get music you're allowed to use
Check the licence on every track, and keep a note of the attribution if one is required.
- **Pixabay Music** (free, no attribution needed): https://pixabay.com/music/
- **YouTube Audio Library** (free, some tracks need credit): studio.youtube.com → Audio Library
- **Uppbeat** (free tier with attribution): https://uppbeat.io
- **Free Music Archive** (varied licences): https://freemusicarchive.org

Good search terms: "lofi chill", "happy acoustic", "dreamy romantic piano", "dark chill beat".
Keep each file under ~5 MB (a 2–3 minute loop at 128 kbps is plenty).
